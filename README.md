# AudioAZ Showfile — 쇼파일 생성기

채널시트(`.numbers`, `.xlsx`)를 업로드해 Yamaha DM7 · KLANG · Waves SuperRack Performer
호환 쇼파일을 생성하는 무료 웹앱/Mac 앱입니다.

- 온라인: 채널시트 분석·검토 체험판 (생성은 오프라인 앱)
- 오프라인(Mac, Apple Silicon): 사이트에서 다운로드 — 3종 쇼파일 실제 생성

## 법적 고지

- 이용약관·면책: [TERMS.md](TERMS.md) — 사용 전 필독. 사용 시 동의로 간주됩니다.
- Yamaha, DM7, KLANG, Waves, SuperRack 등은 각 소유자의 상표입니다. 본 소프트웨어는
  해당 제조사와 제휴·후원·승인 관계가 없는 독립 소프트웨어이며, 상표는 파일 형식
  호환 표시 목적으로만 사용됩니다.
- 소프트웨어와 생성 파일은 무보증(AS IS)으로 제공됩니다. **실제 공연·행사 사용 전
  반드시 장비에서 사전 점검하십시오.**
- 온라인 업로드 파일은 분석 목적에만 임시 사용 후 자동 삭제됩니다.

## Deploy

Render Blueprint에서 `render.yaml`을 사용하거나 Dockerfile로 Web Service를 배포합니다.
