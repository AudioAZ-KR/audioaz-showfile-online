쇼파일 생성기 (AudioAZ) — 설치 안내

1) 「쇼파일 생성기.app」을 응용 프로그램 폴더(또는 원하는 위치)에 복사하세요.

2) 인터넷으로 받은 경우 macOS 보안(Gatekeeper) 때문에 첫 실행이 차단될 수 있습니다.
   터미널에 아래 한 줄을 붙여넣으면 해제됩니다 (관리자 암호 불필요):

   xattr -cr "/Applications/쇼파일 생성기.app"

3) 더블클릭하면 브라우저에 생성기 화면이 열립니다.

- 파이썬 등 별도 설치가 전혀 필요 없습니다 (모두 내장).
- Apple Silicon(M1 이상) Mac 전용입니다.
- 본 소프트웨어는 무료이며, 사용 시 이용약관·면책 고지(화면 하단 링크)에 동의한
  것으로 간주됩니다. Yamaha·DM7, KLANG, Waves·SuperRack 등은 각 소유자의 상표이며
  본 소프트웨어는 해당 제조사와 무관한 독립 소프트웨어입니다.
- 생성 파일은 공연 전 반드시 장비에서 사전 점검 후 사용하세요.
