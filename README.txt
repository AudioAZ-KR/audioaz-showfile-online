쇼파일 생성기 — 서버(Docker) 배포 패키지

인터넷에 올려서 누구나 브라우저로 쓰게 하려면:

1) 호스팅 계정 필요 (추천: fly.io 또는 render.com — 무료/저가 티어 있음)
2) 이 폴더째 업로드하고 Docker로 빌드하면 끝:
   docker build -t showfile .
   docker run -p 8787:8787 showfile
   → http://서버주소:8787

주의:
- 공개 서버에 올리면 누구나 접속 가능 — 팀 외부에 노출하지 않으려면
  호스팅의 접근 제한(비밀번호/IP 제한) 기능을 켜세요.
- 서버 환경에서는 '폴더 변경/다른 파일' 대화상자(맥 전용)가 동작하지 않으므로
  시트는 업로드 방식이 필요합니다 — 공개 배포를 확정하면 업로드 UI를 추가해 주세요.
- 로컬/현장에서는 앱의 "같은 네트워크에서 접속 허용" 토글이 훨씬 간단합니다.
